# Voltara Solar — Landing page

Sitio de presentación de **Voltara Solar**, una identidad para el proyecto académico de Photon Labs en la materia TE1020 (Análisis de Circuitos Eléctricos).

**Leyenda:** Energía inteligente, decisiones que brillan.

## Contenido

- `index.html`: página completa con estilos y JavaScript, sin dependencias externas.
- `assets/logo-icono.png`: versión del símbolo del logo para menú y favicon.
- `assets/logo-voltara.webp`: logo original optimizado.
- `assets/paneles-solares.webp`: imagen visual del encabezado.

## Publicar en GitHub Pages

1. Entra a https://github.com/new y crea un repositorio público, por ejemplo `voltara-solar`.
2. Sube **`index.html` y la carpeta `assets`** a la raíz del repositorio (el `README.md` es opcional). No subas solamente el ZIP.
3. En tu repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`; guarda.
6. La URL será similar a `https://TU_USUARIO.github.io/voltara-solar/` cuando GitHub termine de publicar.

La página no necesita hosting de pago, base de datos ni instalación de dependencias. Se puede abrir localmente haciendo doble clic en `index.html`.

## Nota académica

Esta es una landing page de la primera etapa. El simulador eléctrico y el cotizador no están implementados todavía; la página los presenta como funciones en desarrollo. Los cálculos, la selección de equipos y el reporte PDF se añadirán en las siguientes fases del proyecto.
